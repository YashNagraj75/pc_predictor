2Why "distance" is a hard floor, not a suggestion

Run only T relaxation steps and any node farther than T from the output has an error of exactly zero — not small, zero — because the wave hasn't reached it yet. A zero error gives a zero weight gradient (Exercise 7), so that node receives no update at all.
